# MoE-LoRA：5 个 epoch 结果复核与下一步计划

日期：2026-09-17。对象：`output/moe_lora_long_20260917_seed20260913/`。
本次分析已完成日志核对、最佳 checkpoint 重新评估、固定路由推理消融与 Leveling 验证对照；下一阶段训练尚未启动。

## 1. 结论

当前 MoE-LoRA 在这份验证集上优于 epoch 0 的零增量策略，最佳 epoch 为 **2**，平均 R/N 改善 **2.38%**。
第 3–5 个 epoch 没有刷新最优值，因此后续比较使用 **best.adapter.pt**，而不是 latest.adapter.pt。

但固定已训练专家、取消输入相关路由后，验证结果基本不变：50/50 固定路由甚至略低于动态路由，差异的配对区间跨 0。
现有证据支持“低秩适配有效”，**尚不支持“动态 MoE 路由比普通 LoRA 更有效”**。
下一步最优先补同一层的普通 LoRA rank-16 对照，之后再决定路由消融或多种子确认。

## 3. 每个 epoch 的结果

R/N 为逐实例“搬移次数 / 集装箱数”的平均值，越低越好。R 为每实例平均搬移次数。

| Epoch | 平均 R/N | 相对 epoch 0 降低 | 平均 R | 相对 epoch 0 胜 / 平 / 负 |
|---|---:|---:|---:|---:|
| 0：零增量参考 | 0.951623 | — | 120.570 | — |
| 1 | 0.929636 | 2.310% | 117.715 | 140 / 15 / 45 |
| **2：最佳** | **0.928947** | **2.383%** | **117.640** | **138 / 10 / 52** |
| 3 | 0.929996 | 2.273% | 117.780 | 137 / 7 / 56 |
| 4 | 0.930247 | 2.246% | 117.830 | 141 / 7 / 52 |
| 5：最新 | 0.932368 | 2.023% | 118.085 | 135 / 12 / 53 |

最佳模型在 200 个实例上总计少搬移 **586 次**，平均每例少 **2.93 次**。
对相同实例做 20,000 次 paired bootstrap，最佳减去 epoch 0 的平均 R/N 差为 -0.022675，探索性 95% 区间约 [-0.028069, -0.017159]。

**统计范围：**这些是同一验证集上的实例重采样区间，best 也在这份验证集上选出，未校正 checkpoint 选择与多重比较，更未包含训练种子的波动。
这不是独立测试集结果，不能据此宣称最终泛化性能或多种子优势。

四种布局的平均指标均改善，没有发现收益只来自某一个布局：

| 栈数×层数 | 验证实例 | epoch 0 R/N | epoch 2 R/N | 胜 / 平 / 负 |
|---|---:|---:|---:|---:|
| 20×8 | 79 | 0.889949 | 0.874867 | 52 / 6 / 21 |
| 20×10 | 47 | 1.119332 | 1.084627 | 37 / 0 / 10 |
| 24×8 | 38 | 0.909113 | 0.878384 | 27 / 2 / 9 |
| 25×8 | 36 | 0.912880 | 0.897748 | 22 / 2 / 12 |

另对同样 200 个 validation 实例运行公共信息 Leveling：平均 R/N=1.198854、平均 R=151.775，最佳 MoE 在 200 例全部优于它。
Leveling 是基本参照，不能用这个差距替代与相近容量普通 LoRA 的比较。

训练过程未出现溢出跳过或零优势实例；梯度范数正常。后期验证略回退，提示已进入平台或参数漂移阶段；单次运行不足以确定是过拟合。
RL 的归一化策略损失不需要逐 epoch 单调下降，模型选择仍以 greedy validation R/N 为准。

## 4. 路由是否已经发挥作用

重新加载 epoch 2 的 best，在完整 200 个验证实例上复评，逐实例搬移数与原日志完全一致。
收集其验证轨迹中的 510,503 个栈表示，得到：

- 平均路由权重为 **[0.460952, 0.539048]**。
- 平均路由熵 **0.688833**；两个专家均匀分配时的最大熵为 log(2)=0.693147。
- 专家 0 权重的 10% / 50% / 90% 分位数为 0.43120 / 0.45599 / 0.49739；完整范围约 0.40090–0.54460。
- 没有任何被观察栈的单专家权重超过 0.7。两个专家都有贡献，不能称为单专家塌缩；路由目前只是较温和的权重调整。

本次只在内存中改变路由，保留已训练专家与冻结基座，分别跑完整验证轨迹：

| 推理方式 | 平均 R/N | 平均 R | 比原动态路由少搬移的总次数 |
|---|---:|---:|---:|
| 原动态路由 | 0.928947 | 117.640 | 0 |
| 固定 50/50 | 0.928662 | 117.600 | 8 |
| 固定平均权重 [0.460952,0.539048] | 0.928638 | 117.595 | 9 |

固定 50/50 减去动态路由的 R/N 差为 -0.000285，paired 95% 区间约 [-0.001286, 0.000725]。
固定平均权重的对应区间为 [-0.001074, 0.000500]。两个区间均跨 0，不能宣称固定路由更优，也没有观察到动态路由的额外推理收益。

注意：固定平均权重取自当前验证轨迹，是分析性消融，不是新的独立泛化结果；固定路由仅在推理时施加，不能排除动态路由在联合训练期间影响了专家学习。
专家也并非相同矩阵：epoch 2 两个有效增量矩阵的余弦相似度约 0.258。但参数不同本身不能证明任务分工或动态路由收益。

### C. 根据 rank-16 结果选择一个方向，避免同时扩大全部实验

**若普通 LoRA 与 MoE 接近或更好：**目前缺少动态路由价值证据。为了继续验证 MoE 假设，优先只做一个去均衡项的实验（MoE 原结构、系数 0、相同 seed/预算），检查路由变化与质量是否一起改善。
若去掉均衡项发生塌缩，再考虑系数 0.001；不要只为了把熵降下来而强迫 top-k 或增加专家。
本轮均衡损失较小也不能单独证明系数过强或过弱，需要实际对照。

**若 MoE 有明确优势：**先保留该结构，增加两个训练种子 20260923、20260933，对 MoE 与 LoRA-r16 做配对重复。
本轮 seed20260913 已有 MoE，阶段 B 补 LoRA；再增加两种方法×两个 seed，共四轮，最终各三个 seed。
报告每 seed 最佳 R/N、三个 seed 均值/标准差、胜出方向、配对实例差、布局分组与有效更新数。

若“推理固定路由仍一样好、但 MoE 训练优于普通 LoRA”，后续再加入从训练开始就固定 50/50 的双专家消融，区分联合训练效应与输入相关路由效应。
它应复用一个训练循环，不恢复旧 Q8/D8 队列或全局多模式分发表。

预算参考：本次 MoE 五个 epoch 约 48 分钟。阶段 B 先预算约一轮训练时间；多种子阶段额外四轮粗估约 3.2 小时，具体以各方法同机实测为准。
暂不无条件同时搜索 rank、专家数、学习率、插入位置和均衡系数。
